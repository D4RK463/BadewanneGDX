Dies ist die Portierung der Badewannenverschwörung in libGDX. Erstellt um
 1. Das Spiel vielleicht mal auf neuen Systemen zum Laufen zu bringen
 2. Kotlin zu lernen
 3. libGDX auszuprobieren 

## Starten
Für die Desktop-Variante:
org.wanne.lwjgl3.Lwjgl3Launcher.main

Für die Android-Variante:
org.wanne.android.AndroidLauncher.onCreate
